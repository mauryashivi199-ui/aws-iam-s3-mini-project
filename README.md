AWS IAM & S3 Mini Project

Repo: https://github.com/mauryashivi199-ui/aws-iam-s3-mini-project.git

Skill Nexis – Week 1
Objective

To understand AWS IAM and Amazon S3 by creating an IAM user, creating an S3 bucket, uploading an HTML file, and testing access permissions.

Tasks Completed
Created an AWS IAM user
Created an Amazon S3 bucket
Uploaded index.html to the S3 bucket
Tested private object access
Configured a temporary bucket policy for public access testing
Verified the HTML page through the S3 Object URL
Removed the public bucket policy
Enabled Block All Public Access again
AWS Services Used
AWS IAM
Amazon S3
Project Outcome

The S3 object was successfully uploaded and access permissions were tested. After testing public access, the bucket was restored to a secure configuration with public access blocked.
